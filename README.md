# datwily

**datwily** é uma biblioteca Python para preparação, limpeza e análise inicial de dados.

O objetivo da biblioteca é simplificar tarefas repetitivas feitas antes da análise de dados ou treinamento de modelos de Machine Learning.

A biblioteca utiliza pandas internamente, mas fornece uma API mais simples e organizada para:

* limpeza de dados
* tratamento de valores ausentes
* normalização de colunas
* detecção de outliers
* análise estatística básica
* geração de relatórios
